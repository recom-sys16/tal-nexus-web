Admin Manual

TAL Nexus Website — Operator Guide

1Getting Started

Default password: guardian. Change it in Settings after first login. The password is stored locally in this browser only.

2Voice Chat

  • Tap Mic to speak. Your browser will transcribe your question and send it to TAL Nexus.
  • Keep Voice: On to hear spoken replies through speech synthesis.
  • Use Stop to cancel any ongoing speech output.

3AI Backend

By default the website connects to a local API server at http://127.0.0.1:8787/chat. Start it with Run Tal AI API.command in the app folder. If the server is not running, the website falls back to built-in local answers.

You can point to any compatible endpoint in Settings → Optional AI backend endpoint.

4Security Notes

  • This web version is password-only. Face ID is not included here.
  • All settings and the password live in localStorage for this browser.
  • Clearing browser data resets the password back to guardian.
  • TAL Nexus refuses stealth, malware, and unauthorized access requests by design.

5Troubleshooting

  • No voice? Use Chrome, Edge, or Safari. Firefox may not support Web Speech.
  • Backend not replying? Make sure the API server is running and the endpoint is correct.
  • Forgot password? Clear this site's browser data to reset to guardian.

6Change Admin Password

Change the admin password used to open this manual.
